ROOT MANAGEMENT MUST BE STABLE

Root Management is the first real feature.

Make sure it does the following:

1. User opens Root Management.
2. User sees global root switch.
3. User taps the switch.
4. Safety confirmation dialog appears.
5. After confirmation, call RootShell.checkRoot().
6. RootShell runs: su -c id
7. If stdout contains uid=0, show:
   “Root active for RootDeck.”
8. If unavailable or denied, show:
   “Root not granted or device not rooted.”
9. Log the result in Logs.
10. Show installed apps list with toggles.
11. App toggles must control only RootDeck’s internal allowlist.
12. The app must clearly say:
    “These toggles do not grant real Magisk, KernelSU, or APatch root permission to other apps. They only allow RootDeck to run approved actions targeting selected apps.”
13. Add Open Root Manager button.
14. Detect and open common root managers where possible:

* com.topjohnwu.magisk
* me.weishu.kernelsu
* me.bmax.apatch

15. If no root manager is detected, show:
    “No supported root manager found. Manage root permission from your installed root provider.”
