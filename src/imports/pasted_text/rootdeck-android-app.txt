PROJECT NAME
Use the working name: RootDeck

PRODUCT GOAL
RootDeck is a clean Android 14+ root dashboard for advanced users who already have root access through Magisk, KernelSU, APatch, or another legitimate user-authorized root provider. The app does not exploit devices, does not bypass security, does not hide itself, and does not root phones by itself. It only manages local device tools after the user grants root permission through their existing root manager.

IMPORTANT SECURITY AND ETHICS RULES
- Do not include exploits, privilege escalation, bootloader bypasses, stealth behavior, spyware, persistence, credential access, lockscreen bypasses, FRP bypasses, Play Integrity bypasses, or anti-detection features.
- The app must only run root commands after explicit user confirmation.
- Every dangerous action must have a confirmation dialog.
- Show logs transparently.
- Include a safety disclaimer: “RootDeck requires a device that is already rooted. Use only on your own device.”
- No background root actions without the user pressing a button.
- No automatic deletion, no hidden services, no remote control, no data exfiltration.
